# Ecommerce Frontend (Next.js)

A Next.js TypeScript frontend scaffold for an ecommerce site with Firebase authentication and admin login support.

## Features

- Next.js App Router
- Firebase authentication integration
- Admin login page scaffold
- Shop, cart and product listing pages
- Ready for GitHub source control and Vercel hosting

## Setup

1. Install dependencies:

```bash
npm install
```

2. Copy `.env.example` to `.env.local` and fill in your Firebase values.

3. Enable Google sign-in in your Firebase console.

4. Run the development server:

```bash
npm run dev
```

5. Deploy to Vercel by connecting this repository to Vercel and using the production branch.
